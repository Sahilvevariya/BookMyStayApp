# Book My Stay App

## Overview
Book My Stay App is a console-based Hotel Booking Management System developed using Core Java.  
It demonstrates the use of data structures and software design concepts through incremental use cases.

---

## Features / Use Cases

- UC1: Application Entry & Welcome Message  
- UC2: Room Modeling (OOP Concepts)  
- UC3: Centralized Inventory (HashMap)  
- UC4: Room Search (Read-Only Access)  
- UC5: Booking Request Queue (FIFO)  
- UC6: Room Allocation (Set + HashMap)  
- UC7: Add-On Services (Map + List)  
- UC8: Booking History & Reporting (List)  
- UC9: Error Handling & Validation (Exceptions)  
- UC10: Booking Cancellation (Stack - Rollback)  
- UC11: Concurrent Booking (Thread Safety)  
- UC12: Data Persistence (Serialization)

---
